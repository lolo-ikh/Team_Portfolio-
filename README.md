## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/lolo-ikh/Team_Portfolio.git](https://github.com/lolo-ikh/Team_Portfolio.git)
   ```

2. Install dependencies:

```Bash
cd Team_Portfolio
npm install
```
3. Start the development server:

```Bash
npm start
```
The site will open at http://localhost:3000.
